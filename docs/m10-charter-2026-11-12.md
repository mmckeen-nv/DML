## Mission alignment

The DML exists for fast, accurate ingress/egress into a compact relationship lattice — salience/fidelity-weighted nodes, write-time compaction (the user pays for compaction, not for RAG's read-time context flood), an aging/abstraction ladder that compresses cold nodes into gist while lineage preserves detail (RAG as the full-fidelity drill-down/failover), and an agentic cookbook path where past task successes/failures accelerate future tasks. M8 proved the memory machinery and fairness framework; M9 repaired the policy enough to drive the surface. **M10's job: the policy must drive it *well*.**

## The defect (measured, retained)

The 2026-11-12 held-out campaign (144 scenarios, sealed digest `4478cd7f…`, evidence `/home/test/dml-debug/m8-campaign-heldout-20261112/`, local copy `~/.hermes/cache/scratch/m8-control/campaign-144.jsonl`): the qualified policy's `valid_cited_final` rate is **21.5% (dml) / 18.1% (rag)** — at the M9 "not broken" floor, not a quality level. Decomposition of dml's 113 unsupported finals (all classes reproducible from retained evidence):

1. **Claim-idiom key mismatch (≈50/113):** the answer contains every required truth value word-bounded, but claims carry narrative keys (`"tunnel house delta field dispatch report shading screen condition"`) instead of the truth-key idiom (`"shading_screen_dispatch_condition"`). Correct knowledge, wrong claim shape.
2. **Partial multi-part coverage (≈53/113):** some truths asserted, others omitted (1/2, 1/3, 2/3 patterns) — decomposition of multi-part questions fails to generalize to novel phrasings.
3. **Total miss (≈10/113):** no truths in the answer.
4. **Conflict declaration gap:** in `conflicting_independent_sources`, the policy asserts both conflicting values as facts instead of declaring the conflict (the entire DML-over-RAG margin, 6:1, lives in this family — the behavior is teachable and presentation-sensitive).

These are the same classes M9's curriculum v3 fixed *for the curriculum's own phrasing templates*. The defect is a **generalization gap**, not an absence of capability.
