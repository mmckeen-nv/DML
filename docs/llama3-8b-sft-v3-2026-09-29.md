# Llama 3 SFT v3 training

The once-only fresh paired diagnostic passed **6/6 for v3 and 6/6 for v2**.
Both evidence replays passed. This comparison demonstrates no pass-rate
improvement; the original planning/readiness gates have not been rerun for v3,
and M7 remains open.

The fixed v3 training run completed on the station's GB300. An independent audit
verified all 148 optimizer updates, exact example order, the scheduled final
epoch-two adapter, finite tensors, and owned-container cleanup. This is a new
training candidate; it does not establish task quality or close M7.

V3 was trained to address the [integrated v2 dependent-feedback failure](llama3-sft-integrated-qualification-2026-09-29.md)
with fresh synthetic recovery examples and retention examples for existing
behaviors. Twelve equally represented trajectory families cover retrieval,
paired facts, dependency lookup, selection, supersession, validation recovery,
locator interpretation, irrelevant or repeated results, results without the
requested fact, partial evidence, and missing mutation counterparts. All
trajectories use authentic DML gateway responses and the original verifier.
No evaluation-corpus or prior private qualification fixtures were used.

The retained dataset contains 192 training and 48 development trajectories,
with 592 and 148 positive action targets respectively. Unhelpful actions appear
only as masked history. During independent review, 20 avoidable wrong-query
targets were found in the initial dataset. A pre-training, declared successor
removed their loss contribution while retaining their actions, feedback, and
authorities. No fixtures were resampled or rerun, and no model trained on the
defective predecessor. Earlier declarations and controls remain preserved.

All 740 final targets and 1,200 assistant-history occurrences passed tokenwise
grammar and terminal-token checks. Every training prompt matched the actual
registered compiler in source order and exact token IDs. No truncation or
padding substitutions were used. The longest sequence was 3,458 tokens.

Training started from original `meta-llama/Meta-Llama-3-8B-Instruct`, revision
`8afb486c1db24fe5011ec46dfbe5b5dccdb575c2`, with a fresh LoRA adapter. It did not
continue the v2 adapter. The fixed recipe used rank 16, alpha 32, zero dropout,
all seven projection types, learning rate 0.0001, microbatch one, accumulation
eight, five warmup updates followed by cosine decay, two epochs, and seed
2026092903. Base compute was BF16 and adapter/optimizer state FP32. The
41,943,040 trainable parameters cover 448 adapter tensors. Only the final
scheduled checkpoint is eligible; development loss was not used for selection.

teacher-forced example forwards and zero generation calls. Gradient-checkpoint
backward recomputation is not included in those forward counts. Mean development
completion loss fell from 0.303606 to 0.000387; that is a training diagnostic,
not evidence of successful tool use or factual answers.
